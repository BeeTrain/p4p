# История выпусков

## 1.0.2 — 2026-11-07

- Стабильные обозначения HTTP-маскирования в пределах сессии: одинаковые системные инструкции и история сохраняют префикс для кеша провайдера.
- Сериализация параллельных замен, отдельные снимки восстановления для ответов и ограничение памяти таблиц HTTP.
- Очистка таблиц при удалении сессии, выгрузке плагина и после часа простоя.
- Повторяемый парный A/B-тест кеша: независимые сессии с плагином и без, фиксированный сценарий, метрики каждого вызова и доверительный интервал по парам сессий.
- Копия настроек на время теста, остановка после последовательных сетевых ошибок и продолжение с сохранением полных пар и повторением неполных с новыми префиксами.
- Скрипт проверки кеша, синтетический сценарий и инструкция включены в установочный архив.

## 1.0.1 — 2026-11-06

- Нумерация строк слева в полях «Слова и регулярные выражения», «Применять к хостам» и «Текст для проверки» во всех окнах настроек.
- Синхронная вертикальная прокрутка номеров, учёт пустых строк и изменение ширины колонки для многозначных номеров.
- Горизонтальная прокрутка длинных строк без переноса, чтобы номера оставались напротив соответствующих строк.

## 1.0.0 — 2026-11-06

Первый стабильный выпуск p4p для OpenCode CLI и Desktop 2.2.5.

- Обратимое маскирование выбранных слов и Python regex в запросах моделей.
- Обработка HTTP/JSON, SSE и WebSocket Responses API, включая потоковые ответы и аргументы инструментов.
- Ограничение обработки выбранными хостами моделей.
- Общий построчный словарь и настройки обработки логов, стектрейсов и результатов инструментов.
- Терминальные команды для словаря, хостов, переключения, диагностики и предпросмотра.
- Страница настроек, боковая панель, переключатель и шестерёнка над вводом сообщения в Desktop.
- Импорт и экспорт конфигурации JSON.
- Локальный журнал неуспешных запросов и выгрузка JSON в формате дашборда uitest-loop.
- Пустые словарь и список хостов по умолчанию; конфигурации других проектов не переносятся автоматически.

Установочный пакет публикуется в GitHub Releases. Формат конфигурации остаётся `version: 1`.
