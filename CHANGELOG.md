# История выпусков

## 1.3.0 — 2026-11-13

- Исправлена ошибка RPC `Expected JSON value at ["rows"]` при просмотре запросов без HTTP-статуса, включая незавершённые HTTP-запросы и WebSocket.
- В журнал добавлен список «Логировать:» с режимами «Все запросы», «Успешные» и «Неуспешные». Режим сохраняется в настройках и переносится через импорт/экспорт JSON.
- Выбор применяется к новым HTTP- и WebSocket-запросам после сохранения настроек. Режимы успехов и ошибок сохраняют только подтверждённый результат; прежние записи остаются доступны.
- Добавлены регрессионные проверки JSON-ответа журнала, отбора записей, сохранения режима в интерфейсе и RPC настоящего OpenCode.

## 1.2.0 — 2026-11-10

- Постоянные пулы Python вместо запуска интерпретатора для каждого запроса; повторное использование скомпилированных правил.
- Ограниченный по памяти кеш совпадений в неизменившейся истории с учётом контекста, словаря и диагностики. Таблица замен применяется заново, счётчики сохраняются.
- Демаскирование HTTP JSON и SSE в Node.js. Поддержаны произвольные разрывы UTF-8 и маркеров, независимые каналы, отмена и постепенная передача событий.
- При изменении SSE сохраняется исходная запись чисел, включая большие целые; события без замен передаются без изменения байтов.
- Сохранены лимит обработки regex, изоляция контекстов и снимки таблиц восстановления; добавлены ограниченная очередь, перезапуск зависших процессов и остановка простаивающих работников.
- Исправлено восстановление описаний свойств схем инструментов с именами `format`, `id`, `type` и другими именами протокольных полей.
- Защита черновиков настроек от устаревших ответов сервера при повторном открытии окна.
- Локальные бенчмарки движка и полного пути HTTP-перехватчиков, включая запись журнала, включены в установочный пакет.
- Проверена работа в OpenCode CLI / Desktop 2.2.6.

## 1.1.0 — 2026-11-08

- Окно настроек высотой 80% окна OpenCode; сохранение и перезагрузка закреплены в шапке.
- Маскирование, импорт и экспорт JSON в одной строке; цветной статус сохранённого состояния и доступные с клавиатуры подсказки разделов.
- Единая панель над вводом: `p4p | щит | шестерёнка`, зелёный щит с галочкой и красный щит с крестиком.
- «Журнал запросов» с переключателем записи и компактными строками: успешные, неуспешные и без подтверждённого результата.
- Настройка `recordRequests` включена по умолчанию, совместима с прежними конфигурациями и переносится через импорт/экспорт.
- Начальная запись сохраняется до отправки запроса, завершение проверяется по JSON/SSE/WebSocket; HTTP 200 сам по себе не подтверждает завершение SSE.
- Устранена ложная ошибка `Controller is already closed` при отмене чтения успешного ответа; настоящие ошибки потока и восстановления продолжают записываться.
- Запись запросов WebSocket переключается без переподключения и сохраняется при продолжении сессии.
- Адаптация узкого окна, текстовые подписи статусов, браузерные и интеграционные проверки журнала.

## 1.0.2 — 2026-11-07

- Стабильные обозначения HTTP-маскирования в пределах сессии: одинаковые системные инструкции и история сохраняют префикс для кеша провайдера.
- Сериализация параллельных замен, отдельные снимки восстановления для ответов и ограничение памяти таблиц HTTP.
- Очистка таблиц при удалении сессии, выгрузке плагина и после часа простоя.
- Повторяемый парный A/B-тест кеша: независимые сессии с плагином и без, фиксированный сценарий, метрики каждого вызова и доверительный интервал по парам сессий.
- Копия настроек на время теста, остановка после последовательных сетевых ошибок и продолжение с сохранением полных пар и повторением неполных с новыми префиксами.
- Скрипт проверки кеша, синтетический сценарий и инструкция включены в установочный архив.

## 1.0.1 — 2026-11-06

- Нумерация строк слева в полях «Слова и регулярные выражения», «Применять к хостам» и «Текст для проверки» во всех окнах настроек.
- Синхронная вертикальная прокрутка номеров, учёт пустых строк и изменение ширины колонки для многозначных номеров.
- Горизонтальная прокрутка длинных строк без переноса, чтобы номера оставались напротив соответствующих строк.

## 1.0.0 — 2026-11-06

Первый стабильный выпуск p4p для OpenCode CLI и Desktop 2.2.5.

- Обратимое маскирование выбранных слов и Python regex в запросах моделей.
- Обработка HTTP/JSON, SSE и WebSocket Responses API, включая потоковые ответы и аргументы инструментов.
- Ограничение обработки выбранными хостами моделей.
- Общий построчный словарь и настройки обработки логов, стектрейсов и результатов инструментов.
- Терминальные команды для словаря, хостов, переключения, диагностики и предпросмотра.
- Страница настроек, боковая панель, переключатель и шестерёнка над вводом сообщения в Desktop.
- Импорт и экспорт конфигурации JSON.
- Локальный журнал неуспешных запросов и выгрузка JSON в формате дашборда uitest-loop.
- Пустые словарь и список хостов по умолчанию; конфигурации других проектов не переносятся автоматически.

Установочный пакет публикуется в GitHub Releases. Формат конфигурации остаётся `version: 1`.
