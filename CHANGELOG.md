# История выпусков

## 1.0.0 — 2026-11-06

Первый стабильный выпуск p4p для OpenCode CLI и Desktop 2.2.5.

- Обратимое маскирование выбранных слов и Python regex в запросах моделей.
- Обработка HTTP/JSON, SSE и WebSocket Responses API, включая потоковые ответы и аргументы инструментов.
- Ограничение обработки выбранными хостами моделей.
- Общий построчный словарь и настройки обработки логов, стектрейсов и результатов инструментов.
- Терминальные команды для словаря, хостов, переключения, диагностики и предпросмотра.
- Страница настроек, боковая панель, переключатель и шестерёнка над вводом сообщения в Desktop.
- Импорт и экспорт конфигурации JSON.
- Локальный журнал неуспешных запросов и выгрузка JSON в формате дашборда uitest-loop.
- Пустые словарь и список хостов по умолчанию; конфигурации других проектов не переносятся автоматически.

Установочный пакет публикуется в GitHub Releases. Формат конфигурации остаётся `version: 1`.
